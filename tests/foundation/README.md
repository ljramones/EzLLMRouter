# Foundation package checks

These retained consumers check that locally built private client distributions
install and load from fresh temporary environments. They do not exercise service
behavior or make model requests. Historical WP-FND records preserve resolved
module paths and artifact hashes.

Use the [supported platform checks](../../docs/DEVELOPMENT.md#supported-platform-checks)
for current package, contract and HTTP/TLS qualification. Previous-release
packages are outside the current baseline; these consumers do not create a new
previous-release requirement.
