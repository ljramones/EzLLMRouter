## Decision boundary and alternatives

`v1.105.1` is preferred over a floating/latest release for the *controlled test* because its commit and sdist bytes are now known, its relevant Python paths reconcile, and the selected SDK path exposes a plausible lower transport injection point. It is **not** qualified: the proxy/enterprise closure, SDK source, native build, runtime interception, license and security/soak gates are outstanding. An older release would need the same source/send and advisory review; a later release loses this pin and needs new receipts. If the guarded transport can be bypassed on an enabled path, or a final prepared request cannot be bound without vendor editing, B must report failure and send DEC-09 to the owner for a thin admission/send layer or alternative gateway preserving architecture §5. No fork, vendor patch or alternate product is chosen here.
