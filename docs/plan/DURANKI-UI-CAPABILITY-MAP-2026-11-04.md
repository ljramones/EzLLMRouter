No capability in this map is classified as historical only. The integration-only profile did not previously expose the richer native console UI, report/export buttons, collection creation or account administration forms; those are baseline access gaps, not dropped features. The new operator report and exports preserve the dataset scope and report semantics enforced by the integration ledger. Native budget administration was not established by this source inventory and is not claimed.
